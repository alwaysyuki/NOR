# Security Policy

## Supported Versions

We release security patches and stability updates for the latest versions of **NŌR**.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security and privacy of our users are of paramount importance. NŌR operates on user media, interacts with system workspace notifications, and interacts with AppKit desktop windows.

If you discover a security vulnerability (such as sandbox escape, security-scoped bookmark tampering, or arbitrary command execution during format conversion):

1. **Do not create a public GitHub issue.**
2. Please submit a report privately via [GitHub Security Advisories](https://github.com/alwaysyuki/NOR/security/advisories/new).
3. Include:
   - A description of the vulnerability.
   - Steps or proof-of-concept to reproduce the behavior.
   - The impact on the user's system.
   - Your macOS version and device specifications.

### Response Timeline

- We will acknowledge receipt of your report within 48 hours.
- We will provide a timeline for assessing and addressing the issue.
- Once fixed, a security release will be published and credit will be acknowledged in the release notes (if desired).
